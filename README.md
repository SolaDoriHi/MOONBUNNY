# MOONBUNNY 🌙🐰

A cute Mario-style platformer meme landing page for GitHub Pages.

## What’s inside
- `index.html` — landing page + sections
- `style.css` — design (dark space UI with cute vibes)
- `script.js` — canvas banner animation (MOONBUNNY jumps up green candlesticks to the moon)
- `assets/` — your images (hero + gallery)

## Quick start (GitHub Pages)
1. Create a repo (e.g. `MOONBUNNY`)
2. Upload all files to the repo root
3. GitHub → **Settings → Pages**
4. Source: **Deploy from a branch**
5. Branch: `main` / Folder: `(root)`
6. Wait ~1 minute and open your Pages URL

## Update contract address (CA)
Open `index.html` and replace:

`PASTE_CONTRACT_ADDRESS_HERE`

## Add your social links
In `index.html`, find the `#links` section and paste your URLs.
